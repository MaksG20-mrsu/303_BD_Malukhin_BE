# Описание проекта Task02

## Требования к окружению
Для успешного выполнения автоматизации и развертывания базы данных на компьютере должны быть установлены:
* **Python v.3.x**
* CLI-утилита **SQLite3**

## Инструкция по запуску
Запустите кроссплатформенный скрипт инициализации из терминала:
`./db_init.bat`

После его выполнения будет автоматически запущен скрипт `make_db_init.py`, который сформирует SQL-файл `db_init.sql`. Затем утилита SQLite развернет схему данных и заполнит таблицы, создав готовую базу данных `movies_rating.db` (в соответствии со спецификацией ТЗ).
