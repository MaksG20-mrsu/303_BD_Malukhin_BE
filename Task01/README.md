# Структура файлов данных для Task01

В данном каталоге содержатся исходные файлы датасета и результирующие отчеты:

## Исходные данные
* `ratings.csv` — файл, содержащий оценки пользователей. Содержит столбцы: `userId` (ID пользователя), `movieId` (ID фильма), `rating` (оценка) и `timestamp`.
* `movies.csv` — справочник фильмов (содержит ID, название и жанры).

## Сгенерированные отчеты
* `ratings_count.txt` — содержит информацию о количестве оценок для пользователей с минимальным и максимальным ID.
* `sqlite.txt` — содержит информацию о версии СУБД SQLite и доступных режимах отображения данных (`.mode`).
